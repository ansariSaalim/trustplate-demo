# TrustPlate demo

A clickable prototype of TrustPlate. It helps people find restaurants that match how they eat (halal, Jain, pure veg or vegan), and shows each one with a clear trust level: Certified, Checked by us, Owner-declared or Community.

- Web app (laptop, tablet, phone): https://ansarisaalim.github.io/trustplate-demo/
- Phone app preview: https://ansarisaalim.github.io/trustplate-demo/phone/

Use "View as" at the top to switch between a diner, a restaurant owner and our team. Use "How it works" for a guided tour.

**Every restaurant, certificate and review here is made-up sample data.** It is a front-end prototype only: nothing is saved to a server.

Built with React 18 and htm from a CDN, with no build step.
